# visor-indicadors-cex
Prototip conceptual d’un visor d’indicadors per al seguiment operatiu de les consultes externes hospitalàries desenvolupat en el marc del TFG sobre Lean Healthcare i gestió visual al Parc Taulí.

## Descripció

Aquest prototip ha estat desenvolupat amb HTML, CSS i JavaScript amb l’objectiu d’exemplificar visualment el seguiment d’indicadors operatius relacionats amb la gestió de les consultes externes.

El visor permet representar de manera gràfica:
- Indicadors d’ocupació d’agenda
- Compliment entre agenda prevista i agenda real
- Ocupació per capes
- Reprogramacions
- Forats buits
- Estat global dels indicadors

També incorpora funcionalitats bàsiques de filtratge per servei i classificació visual segons l’estat dels indicadors.

## Objectiu

El desenvolupament del visor té una finalitat exclusivament acadèmica i conceptual dins del TFG:
“Anàlisi i proposta de millora de les consultes externes d’un hospital mitjançant Lean”.

No es tracta d’un producte desplegat en entorn real ni connectat als sistemes hospitalaris.

## Tecnologies utilitzades

- HTML5
- CSS3
- JavaScript

## Execució

Per visualitzar el prototip:

2. Obrir-lo amb qualsevol navegador web
